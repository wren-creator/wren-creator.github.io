PRIVACY POLICY

Last updated: 2026-07-16

What this site collects

Nothing. This is a static page with no forms, no analytics, no cookies, and no third-party trackers. The only way to reach me is the email link in the footer, which opens your own mail client — nothing is transmitted to this site when you click it.

What GitHub collects

This site is hosted on GitHub Pages. GitHub's infrastructure logs standard request data (such as IP address) for hosting and security purposes, independent of anything this site does. See GitHub's Privacy Statement for details.

Fonts

Page text is set in IBM Plex, loaded from Google Fonts. Google may log standard request data (such as IP address) when your browser fetches the font files. See Google's Privacy Policy for details.
